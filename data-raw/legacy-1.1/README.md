# Material from the original 1.1 GitHub repository

Kept for validating version 2.0 against the 2019 paper; not part of the built package.

* `results/`: precomputed 1.x result objects (`taxacom*`, `pathcom*`, `pathmetatab*`,
  `studysum`, `miage`, ...) and the larger 1.1-era datasets (`taxtab.rm7`, ...).
* `extdata/QIIME_outputs/Bangladesh/`: raw QIIME 1 summarised taxa tables (L2 to L7),
  collated alpha diversity, PICRUSt output and the mapping file for the Bangladesh
  study (Subramanian et al. 2014).

Status: not yet inspected for 2.0. Redistribution of the three investigator-provided
studies' data has not been confirmed with the original authors.
